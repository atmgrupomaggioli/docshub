## Running Docshub with Docker

There are 2 modes to run Docshub with Docker: **Interactive Mode** and **Standard Mode** (Production). These instructions are based on the `docker-compose.yml` file, which can either be found in the repository or created by the CLI when initializing the workspace.

## Interactive Mode

Interactive Mode provides Docshub in **development mode**, allowing you to edit and view changes in real time.

```bash
docker compose --profile interactive up -d
```

## Standard Mode

Standard Mode is the **build mode**, used to create your site with the finalized documentation.

```bash
docker compose --profile standard up -d
```
