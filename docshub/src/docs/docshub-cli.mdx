<Alert type="info">
  To run the CLI, it is necessary to have **Node.js version 20 or higher**.
</Alert>

A CLI tool to quickly set up and manage a documentation workspace. **Create directories, configure Docker Compose, and generate blank Markdown documentation** with predefined metadata. Run it instantly using **npx**, no installation needed!

## Run CLI

```bash
npx docshub
```

When you run the CLI, it will prompt you with a menu to choose the desired action.

## Init new workspace

When you select **Initialize Workspace**, the CLI creates the following directory structure. Existing files and directories are preserved and will not be overwritten.

```text
.
├── 📂 docs/
   └── 📄 getting-started.mdx
├── 📂 images/
├── 📄 docker-compose.yml
└── 📄 .env
```

Now that we have the `/docs` and `/images` directories, the `docker-compose.yml` file, the `getting-started.mdx` template, and the default `.env` file generated, how can we start our application to edit the documentation or deploy it to production? ## Create new document

When you select **Create New Document**, the CLI generates a new `.mdx` file inside the `/docs` directory.

<Alert type="warning">Make sure to *Initialize Workspace* beforehand.</Alert>

To build the `.mdx` file, the CLI will prompt you to provide a series of metadata fields, such as the following:

| **Field**      | **Description**                            | **Example**                              |
| -------------- | ------------------------------------------ | ---------------------------------------- |
| `title`        | The main title of the document.            | `"Your Title Here"`                      |
| `sidebarTitle` | The title displayed in the sidebar menu.   | `"Your Sidebar Title"`                   |
| `description`  | A brief description of the document.       | `"A brief description of the document."` |
| `publishDate`  | The publication date of the document.      | `"2024-09-04"`                           |
| `author.name`  | The name of the document's author.         | `"Your Name"`                            |
| `author.url`   | A link to the author's profile or website. | `"https://your-profile-link.com"`        |
