## Creating a new document manually

<Alert type="info">
  Make sure to create a **getting-started.mdx** file beforehand. It is a necessary step for accessing the application for the first time.
</Alert>

1. Create a new file in the `src/docs` (source code) or `/docs` volume (docker) directory with the `.mdx` extension.

```bash
# Source code:
src/docs/example.mdx

# Docker:
./docs/example.mdx
```

2. At the beginning of the document, make sure to include the following parameters:

```mdx
---
title: "Example Document"
sidebarTitle: "Example Document"
description: "Example Document description"
publishDate: "2024-09-04"
---

## Example Heading
```

<Alert type="info">
  Review the full list of available parameters at the end of this page.
</Alert>

3. Write your content in the document using [**Markdown**](https://www.markdownguide.org/basic-syntax/) syntax. Also, you can use the following components:

## Params

- `title` (required): The title of the document.
- `sidebarTitle` (required): The title of the sidebar.
- `description` (required): The description of the document.
- `category` (optional): The category of the document.
- `publishDate` (required): The publish date of the document.
- `author` (optional):
  - `name`: The name of the author.
  - `url`: The URL of the author.
