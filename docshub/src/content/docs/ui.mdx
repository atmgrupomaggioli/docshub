## Images

<UiBlock component="component" title="Images">

<Image src="/logo/docshub.jpg" width="64" height="64" alt="Docshub Logo" />

</UiBlock>

There are two ways to add images to your documentation:

- Using Markdown syntax:

```md
![Docshub Logo](/logo/docshub.jpg)
```

- Using the [`<Image>` Astro Component](https://docs.astro.build/en/guides/images/#images-in-mdx-files):

```mdx
---
title: My Docshub Page
---

import { Image } from "astro:assets";

<Image src="/logo/docshub.jpg" width="64" height="64" alt="Docshub Logo" />
```

## Document Card

Add a card that redirects to a document in your application. It receives the `documentSlug` parameter, which refers to the **filename** of the document.

<UiBlock component="component" title="Document Card">

<DocumentCard documentSlug="getting-started" />

</UiBlock>
```html
<DocumentCard documentSlug="getting-started" />
<!-- src/content/docs/getting-started.mdx -->
```

## Endpoint

<UiBlock component="component" title="Endpoint">

<Endpoint
  method="GET"
  title="Example endpoint title"
  description="Example endpoint description"
  label="STABLE"
>

```bash
https://example.com/end/point/resource
```

```tsx
// Your markdown code here
```

</Endpoint>

</UiBlock>

```tsx
<Endpoint
  method="GET"
  title="Example endpoint title"
  description="Example endpoint description"
  label="STABLE"
>
  // Code
</Endpoint>
```

- `Method` properties:

```ts
export type Method = "GET" | "POST" | "PUT" | "PATCH" | "DELETE";
```

- `Label` properties:

```ts
export type Label = "DEPRECATED" | "BETA" | "ALPHA" | "STABLE";
```
